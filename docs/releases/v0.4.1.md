# Sasta v0.4.1

Sasta's Android interface has been rebuilt in React Native: native text inputs, four bottom tabs, stack navigation, product comparison screens and Android sharing. The shopping websites remain inside their own sign-in screens.

- Preserves the Android package and signing key, and migrates saved lists, cart, location and account data when updating from v0.3.2.
- Keeps multiple named shopping lists, selected items and quantities, list backups, cheapest-cart choices and Blinkit checkout hand-off.
- Bounds stalled searches and refreshes, keys cached prices by coordinates, and preserves cart edits made while a price refresh is running.
- Removes old offers when a successful refresh no longer finds a product. Failed refreshes keep the last known price.
- Fixes crypto startup and PKCE hashing, location permission handling and filter reset between searches.
- Fixes a Cart screen crash caused by importing navigation hooks from a different navigation context, and recreates shopping pages after network failures.
- Keeps bottom-tab labels and icons above Android's system navigation area.
- Builds the native app in GitHub Actions and gates publication on lint, type checking, regression tests and an Android emulator smoke test. APK checksums are included.

## Current limits

Blinkit is the only live search adapter. Other apps are labelled coming soon; connecting them does not yet add their prices. Website availability, platform sign-in and personal offers depend on the provider. End-to-end account login still needs the owner's OTP and has not been certified by the automated smoke test. Always confirm stock, final fees and total in the shopping app before paying.

Install the APK over the old version to preserve local data; do not uninstall first.
