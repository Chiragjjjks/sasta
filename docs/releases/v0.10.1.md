# Sasta v0.10.1

A smaller download that is easier to install. The app itself is the same as [v0.10.0](v0.10.0.md).

- **Less than half the size.** The APK is about 27 MB instead of 60 MB. Android unpacks the app's built-in libraries once when it installs, so the phone does the work instead of your data plan.
- **Install help on the website.** The FAQ now says what to do if the APK won't download, install or open: download in Chrome rather than inside WhatsApp or Instagram, open it from Downloads, allow installs from Chrome, get past Play Protect, and uninstall first if an early test build is on the phone.

## Install

Install over your current Sasta to keep your lists, cart and accounts. Every regular release from v0.1.0 on shares one signing key. The only exception is the extra `-android-debug.apk` test files attached to v0.1.0 to v0.3.2: if one of those is installed, Android says "App not installed". Uninstall Sasta first, then install this one.

Sasta needs Android 7 or newer on a 64-bit phone.
