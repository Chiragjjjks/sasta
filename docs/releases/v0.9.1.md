# Sasta v0.9.1

A fix release: four grocery apps and Connect all now actually run on the phone.

- **BigBasket, Flipkart Minutes, Amazon Now and Zepto's backup search can now run.** Since they were added, the script that reads prices inside each of these sites began with a line that stopped it from running, so on a phone they always showed "timed out". Only Blinkit, and Instamart and Zepto through their official servers, returned prices. The script is fixed, and a new test runs every reader the way the phone does.
- **Connect all apps can now type your number.** The same fault stopped it from filling in the number on each app's sign-in page.
- **Swiggy food finds restaurants by name.** Searching `meghana` on the Food tab returned no Swiggy dishes. Sasta now asks Swiggy for that restaurant's dishes.
- Expo SDK 58 patch updates.

## Current limits

Flipkart Minutes and Amazon Now have still not shown a price on a phone: Flipkart needs an exact Flipkart address, and Amazon Now only works if your Amazon session offers a Now store. Several-product search and Food were checked in the browser preview and desktop Chrome, not yet on a phone with live prices. Everything else from [v0.9.0](v0.9.0.md) still applies.

Install over the previous version to keep your lists, cart and accounts. Do not uninstall first.
