# Sasta v0.5.0

Zepto now has a product search adapter. A connected Zepto account no longer appears as “Soon”. Account tests run a real product query and show the matching product count or the reason search could not complete, separately from login verification.

- Adds Zepto storefront search using the site's own signed requests and selected delivery area.
- Adds a Flipkart Minutes search path with delivery-address setup. Regular Flipkart listings are excluded.
- Adds guarded Amazon Now discovery. Only a verified Now-specific storefront can supply prices; Fresh and regular Amazon listings are excluded.
- Adds **Delivery area** and **Test search** controls. Choose the same delivery area in Sasta and each provider before comparing.
- Filters unrelated promoted products and wrong requested flavours or pack sizes. Keeps 48 g and 50 g, single packs and multipacks, liquid volume and weight, and variable packs separate.
- Ships storefront reader scripts as generated text so they also execute in Android Hermes release builds.
- Preserves saved quantities and lists while updating product identities. Serializes storefront searches during cart refresh and cleans up cancelled pages.

## Validation and current limits

The Zepto reader returned 30 real product cards in a browser check. Flipkart's live endpoint returned an address-selection redirect; positive Minutes prices have been checked against a representative HTTP fixture, not a signed-in live catalogue. Amazon exposed Fresh in the available web session, which was excluded; positive Amazon Now prices have not been verified. Both report the actual session/search state instead of promising support from a login alone.

Regression tests cover search matching, saved-data migration, connection reporting, cancellation and cache behaviour. Publication also requires a signed Android build and the emulator upgrade/navigation/persistence/offline checks. Automated tests do not sign in with an owner's OTP or certify personal offers. Provider availability and final fees remain external.

Install over the previous version to keep your saved data; do not uninstall first.
