# Sasta v0.8.0

Connect every app at once: type your number once, and Sasta signs in to each app and fills the OTPs for you.

- **One number, every app.** Account → **Connect all apps at once**. Enter your mobile number (kept encrypted on this phone) and tap **Connect**. Each app's own sign-in page opens at the same time; Sasta taps Login, types your number and requests the OTP, once per app.
- **OTPs filled from your notifications.** Allow **Notification access** for Sasta the first time. Each code is typed into the app the message names (for example "JD-BLNKIT"), or into the only app still waiting. Sasta never guesses between apps. It reads notifications only while it is signing in, for at most 10 minutes, and keeps nothing.
- **See and finish any app.** A sheet shows each app's progress: number entered, waiting for OTP, signed in. Tap an app to see its page and finish by hand when it asks for something else (a password, a captcha).
- Without Notification access, Sasta still types your number everywhere and you type each OTP.

## Current limits

This is the first version tested with real sign-in pages on a phone; some apps may need a tap by hand. Amazon usually asks for a password, so it shows "Needs you". Codes sent only inside an app (not by SMS or notification) can't be read. Instamart and Zepto still use their official sign-in pages.

Install over the previous version to keep your lists, cart and accounts. Do not uninstall first.
